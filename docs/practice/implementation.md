# Latihan melalui chat

Practice adalah domain terpisah dari aktivitas Journey. Permintaan flashcard, kuis, atau exam dibuat melalui agent chat. `ask_user` menggunakan interrupt untuk informasi yang belum jelas; `create_practice` selalu melewati persetujuan LangChain sebelum membuat set. Kartu dan keputusan disimpan bersama run, lalu resume memakai checkpoint PostgreSQL dengan `thread_id` berupa ID chat run. Setiap tulis checkpoint mengunci run dan memeriksa executor, epoch lease, status, serta waktu lease agar executor lama tidak menimpa state setelah pengambilalihan.

Modul tujuan dan sumber dipilih terpisah. Server memeriksa kepemilikan modul/lampiran dan revisi materi sebelum menerima persetujuan dan sebelum membuat set. ID interaksi yang disetujui menjadi kunci idempotensi set. Sumber disalin ke storage Practice sebelum pekerjaan generation diterima, sehingga penghapusan chat tidak menghilangkan input worker.

Worker mendispatch pekerjaan dari baris PostgreSQL ke queue BullMQ. Generation memproses maksimal 10 item per batch, menyimpan checkpoint batch yang valid, memvalidasi output provider, dan menandai seluruh item `ready` dalam satu transaksi. Lampiran yang belum memiliki teks ekstraksi diproses dengan adapter OCR worker dari salinan Practice. Kunci jawaban dan rubrik disimpan terpisah dari DTO pengerjaan.

Endpoint publik berada di `/api/v1`: `POST /chat/threads/:threadId/runs/:runId/interactions/:interactionId/respond`, `GET /modules/:moduleId/practices`, `GET|PATCH /practices/:practiceId`, `POST /practices/:practiceId/retry`, `POST|GET /practices/:practiceId/attempts`, serta `GET|PATCH /practice-attempts/:attemptId`, `POST /practice-attempts/:attemptId/submit`, dan `POST /practice-attempts/:attemptId/retry-evaluation`. Semua endpoint memerlukan sesi pemilik. Daftar Practice menggunakan cursor; item publik tidak memuat kunci atau rubrik.

Attempt menyimpan jawaban dengan revisi server. Deadline exam berasal dari waktu mulai di server; dispatcher otomatis mengirim exam yang waktunya habis meskipun browser tertutup. Pilihan ganda dan benar/salah dinilai deterministik; esai dinilai dalam batch maksimal lima jawaban. Kegagalan evaluasi mempertahankan jawaban untuk retry. Penyelesaian pertama set memberi 10/20/30 XP, dibatasi 100 XP Practice per hari berdasarkan timezone profil, di dalam transaksi yang mengunci statistik pengguna. Practice tidak mengubah progres Journey, mastery, atau adaptive intervention.

Pemeriksaan statis lokal: `bun db:check`, typecheck paket terdampak, lint/format, dan build web. Verifikasi runtime terpisah mencakup HITL, autosave/deadline, idempotensi, dan XP; jalankan migrasi di lingkungan pengujian sebelum verifikasi tersebut. Migrasi baru bersifat additive. Uji provider nyata dan browser terautentikasi perlu dijalankan terpisah di lingkungan yang memiliki kredensial dan data materi representatif.
